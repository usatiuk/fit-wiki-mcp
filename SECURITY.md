# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security problems, leaked cookies, auth bypasses, or credential-store bugs.

Use GitHub Security Advisories for this repository:

https://github.com/usatiuk/fit-wiki-mcp/security/advisories/new

If advisories are unavailable, email stepan@usatiuk.com and include only enough detail to establish impact. Do not include real FIT Wiki cookies, passwords, or private page content.

## Supported Versions

Only the latest npm release is supported for security fixes.
